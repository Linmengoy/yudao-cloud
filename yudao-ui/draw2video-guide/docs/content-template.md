# 全业务模块内容模板与维护流程

本页定义 Draw2Video 使用指南的统一内容结构、模块目录占位和运营维护流程。后续每个业务模块都按同一模板补齐，未完成正文的模块保留“待补充”状态，避免前台展示空白内容。

## 模块目录

| 模块 | 适用对象 | 维护责任 | 状态 |
| --- | --- | --- | --- |
| 注册登录 | 普通用户、运营 | 产品运营 | 待补充 |
| 创作画布 | 普通用户、创作者 | 产品运营 | 待补充 |
| 模型选择 | 普通用户、创作者 | 产品运营 | 待补充 |
| 任务中心 | 普通用户、客服 | 产品运营 | 待补充 |
| 资产中心 | 普通用户、客服 | 产品运营 | 待补充 |
| 钱包计费 | 普通用户、财务、客服 | 产品运营 + 财务 | 待补充 |
| 安全审核 | 运营、审核员 | 运营审核 | 待补充 |
| 管理后台 | 管理员、运营 | 产品运营 | 待补充 |

## 内容模板

每篇指南必须包含以下段落：

1. 适用对象：说明谁需要阅读本文。
2. 操作入口：写清前台或后台菜单路径。
3. 操作步骤：按实际点击顺序列出步骤。
4. 截图占位：使用统一图片命名，暂缺截图时标记“待补充截图”。
5. 注意事项：说明权限、计费、审核、数据可见性等限制。
6. 常见问题：至少提供 1 个真实用户问题或运营预判问题。

## 维护流程

1. 产品或运营按模板编写草稿。
2. 业务负责人确认入口、步骤和边界条件。
3. 发布前检查截图、链接、术语和权限说明。
4. 发布后由构建流程导出为 Docusaurus 文档快照。
5. 模块新增或功能调整时，同步更新对应指南页。
